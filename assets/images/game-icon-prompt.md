# Moving Day game icon draft v1

Generated with the built-in image_gen tool using Claude B's assets/renders/icon_reference.png as the visual reference. The original generated PNG is preserved at assets/images/ICON_GameDraft_v1.png. This is concept art for the experience icon, not a gameplay screenshot or thumbnail. Final launch selection and publishing are separate.

## Final prompt

Use case: ads-marketing. Asset type: square 1024 x 1024 game icon for the user's own Roblox game Moving Day. Input image is Claude B's original game-asset reference render, used as subject and visual-design reference. Create a polished, cheerful low-poly illustration of exactly the same core scene: two simple blocky movers in yellow hard hats, one blue shirt and one orange shirt, cooperatively holding the teal-and-cream two-seat couch; the coral-red pickup nearby with cardboard boxes, lamp and television in its bed. Preserve these recognizable asset shapes and colors from the reference. Recompose for a highly readable app icon: tightly framed large couch and both movers' heads/hands in the foreground, pickup behind, clean pale sky and grassy ground, strong silhouettes, friendly bright daylight, restrained shadows, flat-shaded polygon surfaces, no photoreal textures. Keep characters generic and consistent with the supplied user-owned reference, without adding characters from other games. Both movers must visibly support opposite couch ends; no extra limbs or floating cargo. Do not add any feature or object absent from the reference. No text, letters, logos, watermarks, UI, coins, promotional badges, speed trails, explosions or scenery buildings. Safe margin around subjects for square icon cropping; avoid the reference's excessive blank upper half. Opaque background.

## Review

The generated image preserves the reference's couch, movers, loaded pickup, vase and color scheme, with a tighter frame and brighter background. No text or unimplemented mechanics are shown. It is stored unchanged at the generator's delivered resolution; this draft has not been set as the experience icon. Final sizing and Creator Hub application belong to the launch handoff.
